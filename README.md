# Rebone 会員サイト ワイヤーフレーム（ライブ起点モデル）

毎週水曜のライブレッスンを起点に、翌週の1週間へ割り振る設計のワイヤーフレームです。
カレンダー機能（`rebone-wireframe-calendar`）も、このリポジトリに合流させています。

https://geet-inc.github.io/rebone-wireframe-live/

## メモ

- ファイル名は要件定義ノートと合わせるため、画面の削除・合流のあとも変えていません。一覧の表示番号だけを 01〜04 に振り直しています。
- ホームの「テーマの中身」への導線は、ボタンごと削除しています。今月のテーマのブロックは「今週は、◯◯のスイッチ」だけが残る形です。
- きろくの色は5分類（今月のテーマ／エクササイズ集／ライブ／Switch Lab／複数うけた日）です。1日に2本以上うけた日は「複数」の色にまとめ、本数のバッジは出しません。
- あゆみの月ごとの印は、季節をあらわす絵文字です。色を情報として使っているのは、03・04 のカレンダーの中だけという整理は変えていません。
- あゆみは次のフェーズに回しました。きろく画面からの導線も、ボタンごと外しています。
- 内訳（円グラフ）のグレー階調は、部位別の色をまだ決めていないという意味です。
- Switch Lab は画面（`05-switchlab.html`）のみ削除しました。ホームの Switch Lab ブロックと、カレンダーの中の Switch Lab（SW）の記録は、機能としては残る前提でそのままにしています。ブロックのボタンの行き先だけ `href="#"`（エクササイズ集などと同じ、行き先未定のプレースホルダ）です。
- ボトムナビの4つ目は、確定している5タブ構成に合わせて全画面「きろく」で統一しています。タブ名の改称は未確定の論点です。
