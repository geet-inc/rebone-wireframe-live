# Rebone 会員サイト ワイヤーフレーム（ライブ起点モデル）

月に4本のライブレッスンを軸に、1週間はエクササイズ集で組んだカリキュラムを進める設計のワイヤーフレームです。
カレンダー機能（`rebone-wireframe-calendar`）も、このリポジトリに合流させています。

https://geet-inc.github.io/rebone-wireframe-live/

## 今回の修正（2026-08-19・お打ち合わせのご指摘より）

- **ホームのいちばん上に、一言メッセージの枠を置きました。** 閉じるボタンは置いていません。一度出したメッセージは、消えずに残る仕様です
- **「今週は、◯◯のスイッチ」の表記を削除しました。** 今月のテーマのブロックは、テーマ名と説明だけになります
- **その月のライブレッスン4本を、ホームの上部に一覧で置きました。** アーカイブへ移動する導線よりも、「今月なにをやるか」が見えることを先にしています
  - まだ実施していない回は、文字をうすく落としています
  - まだの回のサムネイルは、共通の IKUM ロゴです。回ごとの画像を、そのつどご用意いただく必要はありません
  - 出しているのは、ミニサムネイル・タイトル・日付の3つです
  - 「過去のライブレッスンを見る」は、4本の下に小さく残しています
- **ライブのある日（02）は、当日の1本だけを大きく、のこりの3本を小さくならべます。** 当日の見え方を強くするためです
- **「今日の1本」は、曜日にかかわらず毎日出します。** ライブレッスンとは切りはなした扱いです
- **「今週のスケジュール」は縦積みのままです。** 横スクロール案は、1週間を通しで見られないため見送りました
  - サムネイルは入れていません。エクササイズ集のタイトルと、長さだけです
  - 中身はライブの切りぬきではなく、エクササイズ集の動画を組んだ1週間のカリキュラムです
  - 時間割として見ていただくもので、ここから動画へは移動しません
- **「あなたの積み上げ」は、ホームから外しました。** きろく（カレンダー）へ集めています
- **きろくの並びを、上から「今月の目標・やること」→「実績」→「カレンダー」に変えました。** 日付をタップすると、その日に受けたレッスンが出ます
- 過ぎた月のデータは、編集できない前提です（実装のうえで、編集できるほうが簡単であれば、できてもかまいません）

## メモ

- ファイル名は要件定義ノートと合わせるため、画面の削除・合流のあとも変えていません。一覧の表示番号だけを 01〜04 に振り直しています。
- ホームの「テーマの中身」への導線は、ボタンごと削除しています。今月のテーマのブロックは、テーマ名と説明だけが残る形です。
- きろくの色は5分類（今月のテーマ／エクササイズ集／ライブ／Switch Lab／複数うけた日）です。1日に2本以上うけた日は「複数」の色にまとめ、本数のバッジは出しません。
- あゆみの月ごとの印は、季節をあらわす絵文字です。色を情報として使っているのは、03・04 のカレンダーの中だけという整理は変えていません。
- あゆみは次のフェーズに回しました。きろく画面からの導線も、ボタンごと外しています。
- 内訳（円グラフ）のグレー階調は、部位別の色をまだ決めていないという意味です。
- Switch Lab は画面（`05-switchlab.html`）のみ削除しました。ホームの Switch Lab ブロックと、カレンダーの中の Switch Lab（SW）の記録は、機能としては残る前提でそのままにしています。ブロックのボタンの行き先だけ `href="#"`（エクササイズ集などと同じ、行き先未定のプレースホルダ）です。
- ボトムナビの4つ目は、確定している5タブ構成に合わせて全画面「きろく」で統一しています。タブ名の改称は未確定の論点です。
